# Python Activity-Based Learning

## Description
This project contains **10 Python case studies** completed as part of the Python Activity-Based Learning assignment. Each case study demonstrates a simple real-world problem solved using basic Python concepts such as input/output, arithmetic operations, conditional statements, loops, and string handling.

## Case Studies Included
1. **Manufacturing Cost and Profitability Analysis** – Calculates total manufacturing cost and determines profit, loss, or no profit and no loss.
2. **Campus Event Financial Planning** – Calculates event expenses and identifies a sponsorship surplus, shortage, or exact coverage.
3. **Attendance Recovery Computation** – Calculates attendance percentage and the additional consecutive classes needed to reach 75% attendance.
4. **ATM Transaction Sequence Simulation** – Simulates a deposit or withdrawal and displays the updated account balance.
5. **Student Performance Trend Analysis** – Compares marks from two examinations and identifies improvement, decrease, or no change.
6. **Multi-Product Shopping Budget Constraint** – Calculates shopping costs and checks whether the purchase fits the available budget.
7. **Traffic Violation Penalty Calculator** – Displays a sample penalty based on the selected traffic violation.
8. **Password Policy Validation Engine** – Checks whether a password contains at least eight characters.
9. **String-Based Examination Answer Evaluation** – Compares a student's answer with the correct answer without considering uppercase/lowercase differences and awards 1 or 0 marks.
10. **Food Waste Monitoring System** – Calculates leftover meals and the food-waste percentage, then checks whether waste exceeds 20%.

## Contents of Each Case Study
Each case study is organized with:
- Problem Statement
- Objectives
- Assumptions
- Algorithm
- Flowchart
- Pseudocode
- Python Source Code
- Test Cases
- Screenshots / Outputs
- Conclusion

## Concepts Used
- `input()` and `print()`
- Variables and arithmetic operations
- `if`, `elif`, and `else`
- `while` loop
- String methods such as `.lower()`
- String length using `len()`
- Basic calculations and comparisons

## How to Run
1. Install Python 3 if it is not already installed.
2. Open the Python source code for the case study you want to execute.
3. Save the code in a file with a `.py` extension.
4. Run the file using Python or an IDE such as IDLE or Visual Studio Code.
5. Enter the requested values when prompted and view the output.

## Notes
- The programs are intended for beginner-level practice and use simplified assumptions for educational purposes.
- The traffic penalty amounts are illustrative values for the programming exercise, not official legal fines.
- For the attendance program, the target attendance percentage is 75%.
- For the food-waste program, the threshold used is 20%.
